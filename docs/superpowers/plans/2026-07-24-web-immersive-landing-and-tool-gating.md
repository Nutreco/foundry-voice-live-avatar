# Immersive Landing Screen + Agent-Mode Tool Gating Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a clean, fullscreen, interactive avatar view the default landing screen (operator console becomes an opt-in troubleshoot screen reachable via a gear), and show the operator "Tool activity" panel only in agent mode.

**Architecture:** Front-end only. Generalize the client's `operator` concept into a shared `InteractiveView` contract implemented by both the existing `OperatorView` and a new `LandingView`; add routing so the landing view is the default. Non-fatal avatar errors move off the tool panel to a dedicated notice so gating the tool panel never hides them.

**Tech Stack:** TypeScript (strict) bundled by esbuild → `web/src/VoiceLive.Web/wwwroot/app.js`; CSS in `wwwroot/index.html`. No backend/.NET changes (the `ready` frame already sends `mode`).

---

## Testing note (read first)

The front end has **no unit-test runner** (only `esbuild` + `tsc`). The automated verification gate for every task is therefore:

- `cd web/frontend && npm run typecheck` → strict `tsc --noEmit`, expect **no errors**.
- `cd web/frontend && npm run build` → esbuild bundle, expect it to write `../src/VoiceLive.Web/wwwroot/app.js` with no errors.

A final regression task runs `dotnet test web/VoiceLive.Web.sln` (its MSBuild `BuildFrontend` target also rebuilds the bundle). Do **not** add a new JS test framework.

## File Structure

- `web/frontend/src/views.ts` — view builders. Gains `InteractiveView` type, `noteNonFatal` on `OperatorView`, a shared transcript-appender helper, and the new `renderLandingView` + `LandingView` type. Tool panel starts hidden and is gated in `OperatorView.setConfig`.
- `web/frontend/src/main.ts` — `ThinVoiceLiveClient` + `boot()`. Generalizes `operator` → `interactive`, wires optional controls, adds the mute toggle for open-mic/hybrid, routes non-fatal errors to `noteNonFatal`, flips the default route to the landing view.
- `web/src/VoiceLive.Web/wwwroot/index.html` — adds `landing-view` styles, a non-fatal notice style for the operator, and gives `.tools-panel` the card styling it currently lacks (it also honors `hidden`).
- `web/src/VoiceLive.Web/wwwroot/app.js` — generated by `npm run build`; never hand-edited.
- Docs: `README.md`, `web/README.md`, `docs/runbook.md`, `docs/rehearsal-checklist.md` — describe the new default landing screen + agent-mode tool gating.

- [ ] **Step 6: Generalize `wireOperatorControls` → `wireInteractiveControls`**

Replace the whole `wireOperatorControls` method with a version that keys off `this.interactive` and wires the optional controls only when present. (The mute-toggle branch is a no-op until Task 3/4 sets `supportsMuteToggle`; wiring it now keeps the method final.)

```ts
  private wireInteractiveControls(config: ReadyConfig) {
    const view = this.interactive;
    if (!view) return;
    const gated = config.activeMode === "gated";

    if (gated) {
      view.holdButton.hidden = false;
      view.holdButton.onpointerdown = (event) => {
        event.preventDefault();
        this.startGatedTurn();
      };
      const endGated = () => this.endGatedTurn();
      view.holdButton.onpointerup = endGated;
      view.holdButton.onpointerleave = endGated;
      view.holdButton.onpointercancel = endGated;
    } else if (view.supportsMuteToggle) {
      view.holdButton.hidden = false;
      view.holdButton.onclick = () => this.toggleMute();
    } else {
      view.holdButton.hidden = true;
    }

    if (view.stopButton) {
      view.stopButton.onclick = () => {
        this.send({ t: "barge-in" });
        this.setStatus("turn", "barge-in sent");
      };
    }
    if (view.repeatButton) {
      view.repeatButton.onclick = () => this.sendSay("Please repeat your previous answer.");
    }
    if (view.safeQuestionButtons) {
      for (const safeButton of view.safeQuestionButtons) {
        safeButton.onclick = () => this.sendSay(safeButton.textContent ?? "");
      }
    }
  }
```

- [ ] **Step 1: Extract a shared transcript appender**

In `web/frontend/src/views.ts`, add this helper near the other module-level helpers (after `setText`):

```ts
function createTranscriptAppender(list: HTMLElement) {
  const liveText: Record<"user" | "agent", string> = { user: "", agent: "" };
  return function addTranscript(role: "user" | "agent", text: string, final: boolean) {
    const existing = list.querySelector<HTMLElement>(`.transcript-line.live.${role}`);
    const line = existing ?? document.createElement("p");
    const transcriptText = final ? text : liveText[role] + text;
    liveText[role] = final ? "" : transcriptText;
    line.className = `transcript-line ${role} ${final ? "final" : "live"}`;
    line.textContent = `${role === "user" ? "You" : "Agent"}${final ? "" : " (live)"}: ${transcriptText}`;
    if (!existing) list.append(line);
    if (final) line.classList.remove("live");
    line.scrollIntoView({ block: "nearest" });
  };
}
```

  holdButton.type = "button";
  holdButton.className = "landing-talk";
  holdButton.textContent = "\uD83C\uDFA4 Hold to talk";
  holdButton.disabled = true;
  holdButton.hidden = true;

  const transcriptToggle = document.createElement("button");
  transcriptToggle.type = "button";
  transcriptToggle.className = "landing-transcript-toggle";
  transcriptToggle.textContent = "\uD83D\uDCAC";
  transcriptToggle.setAttribute("aria-label", "Toggle transcript");
  transcriptToggle.title = "Transcript";

  const panel = document.createElement("aside");
  panel.className = "landing-transcript";
  const panelHeader = document.createElement("header");
  const panelTitle = document.createElement("span");
  panelTitle.textContent = "Transcript";
  const panelClose = document.createElement("button");
  panelClose.type = "button";
  panelClose.className = "landing-transcript-close";
  panelClose.textContent = "\u00D7";
  panelClose.setAttribute("aria-label", "Close transcript");
  panelHeader.append(panelTitle, panelClose);

  transcriptList.className = "landing-transcript-list";
  panel.append(panelHeader, transcriptList);

  const togglePanel = () => panel.classList.toggle("open");
  transcriptToggle.onclick = togglePanel;
  panelClose.onclick = () => panel.classList.remove("open");

  const notice = document.createElement("div");
  notice.className = "landing-notice";
  notice.hidden = true;
  notice.setAttribute("role", "status");

  const errorOverlay = document.createElement("div");
  errorOverlay.className = "landing-error";
  errorOverlay.hidden = true;
  errorOverlay.setAttribute("role", "alert");

  const addTranscript = createTranscriptAppender(transcriptList);

    root,
    avatar,
    holdButton,
    supportsMuteToggle: true,
    setConfig() {
      // The landing screen is intentionally minimal; config drives only the talk control.

      if (name !== "connection" && name !== "webrtc" && name !== "avatar") return;
      if (name === "webrtc" && value === "connected") {

    addTranscript,
    noteNonFatal(message) {
      notice.hidden = false;
      notice.textContent = message;
    },
